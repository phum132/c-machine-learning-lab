# คู่มือ: พยากรณ์รายจ่ายเดือนหน้าด้วย C Machine Learning Lab

หน้า **ML และพยากรณ์** ใช้ประวัติรายจ่ายรายเดือนของคุณ ฝึก Linear Regression ด้วย `cml-lab.exe` แล้วคาดการณ์รายจ่ายแต่ละหมวดของเดือนถัดไป ข้อมูลไม่ออกจากเครื่อง: แอปเขียน CSV ชั่วคราว เรียกโปรแกรม C แล้วลบไฟล์ทิ้ง

## 1. เตรียมเครื่อง (ครั้งเดียว)

1. Build CLI จากโฟลเดอร์หลักของ repo:

   ```powershell
   cd <โฟลเดอร์ที่ clone ไว้>\c-machine-learning-lab
   .\build.bat
   ```

   ได้ไฟล์ `build\cml-lab.exe` แอปจะหาไฟล์นี้เอง ถ้าย้ายไปไว้ที่อื่น ให้ตั้งตัวแปร `CML_LAB_EXE`:

   ```powershell
   $env:CML_LAB_EXE = 'D:\tools\cml-lab.exe'
   ```

2. เปิดแอป:

   ```powershell
   cd personal-finance-tracker
   python main.py
   ```

## 2. ใส่ข้อมูลให้พอ

- บันทึกรายจ่ายย้อนหลังอย่างน้อย **8 เดือน** (แนะนำ 12 เดือนขึ้นไป) ยิ่งนานยิ่งดี แอปใช้สูงสุด 24 เดือนล่าสุด
- เดือนก่อนรายการแรกของคุณจะไม่ถูกนับ เพราะไม่รู้ว่าเดือนนั้นไม่ได้ใช้เงินจริง หรือแค่ยังไม่ได้เริ่มจด
- เดือนปัจจุบันที่ยังไม่จบจะไม่ถูกใช้ฝึก เพราะยอดยังไม่ครบ
- หมวดที่ไม่เคยมีรายจ่ายเลยในช่วงนั้นจะถูกข้าม

## 3. กดพยากรณ์

1. เลือก **เดือนที่ดู** ด้านบน (เช่น `2026-10`) แล้วกด **อัปเดต**
2. ไปแท็บ **ML และพยากรณ์**
3. กด **ฝึกโมเดลและพยากรณ์** รอไม่กี่วินาที

ตัวอย่างผลจริงจากข้อมูลทดสอบ 18 เดือน:

```text
คาดการณ์รายจ่ายเดือน 2026-10: 11,858.96 บาท · ใช้โมเดล CML · ทดสอบ 9 แถว
MAE: โมเดล 120.40 บาท, เฉลี่ย 3 เดือน 461.30 บาท, เท่าเดือนล่าสุด 614.22 บาท
```

| หมวดหมู่ | เดือนล่าสุด | เฉลี่ย 3 เดือน | โมเดล CML | คาดการณ์ที่ใช้ |
|---|---:|---:|---:|---:|
| ค่าน้ำ/ไฟ/เน็ต | 0.00 | 802.33 | 2,357.37 | 2,357.37 |
| อาหาร | 7,860.00 | 7,754.33 | 7,998.13 | 7,998.13 |
| เดินทาง | 1,592.00 | 1,538.67 | 1,503.46 | 1,503.46 |

## 4. อ่านผลอย่างไร

**MAE (Mean Absolute Error)** คือค่าเฉลี่ยของ |ทาย − จริง| หน่วยเป็นบาท ยิ่งน้อยยิ่งแม่น

แอปเทียบ 3 วิธีกับ **3 เดือนล่าสุด** ที่โมเดลไม่ได้ใช้ฝึก:

| วิธี | ทายว่าเดือนหน้า = |
|---|---|
| เท่าเดือนล่าสุด | ยอดเดือนที่แล้ว |
| เฉลี่ย 3 เดือน | ค่าเฉลี่ย 3 เดือนก่อน |
| โมเดล CML | Linear Regression จากยอด 3 เดือนก่อน + เดือนในรอบปี |

แล้ว **ใช้วิธีที่ MAE ต่ำที่สุด** ถ้าโมเดลแพ้การเดาง่ายๆ แอปจะบอกว่าใช้ค่าเฉลี่ยหรือยอดเดือนล่าสุดแทน คอลัมน์ "โมเดล CML" ยังแสดงให้ดูเทียบได้

ในตัวอย่างข้างบน ค่าน้ำ/ไฟ/เน็ตจ่ายทุก 3 เดือน เดือนล่าสุดจึงเป็น 0 การเดาง่ายๆ พลาดทั้งคู่ แต่โมเดลเห็นว่ายอดเมื่อ 3 เดือนก่อน (`prev3`) สูง จึงคาดว่าเดือนนี้จะมีบิลมาอีก

## 5. ข้างในทำงานอย่างไร

1. **สร้างแถวข้อมูล:** แต่ละหมวด แต่ละเดือน t กลายเป็น 1 แถว

   | prev1 | prev2 | prev3 | month_sin | month_cos | target |
   |---|---|---|---|---|---|
   | ยอดเดือน t−1 | t−2 | t−3 | ตำแหน่งเดือนบนวงกลม | | ยอดเดือน t |

   `month_sin/cos` ทำให้ธันวาคมอยู่ใกล้มกราคม ซึ่งตัวเลข 12 กับ 1 ทำไม่ได้

2. **แบ่งตามเวลา:** 3 เดือนล่าสุดเป็นชุดทดสอบ ที่เหลือเป็นชุดฝึก ไม่สุ่มแถว เพราะในชีวิตจริงเราทายอนาคตจากอดีตเสมอ (บทเรียนจากงาน O-NET: สุ่มแถวให้ผลดูดีเกินจริง)

3. **เรียก CLI:**

   ```text
   cml-lab train --type linear --data train.csv --target 5 --header --model model.cml --normalize ...
   cml-lab predict --model model.cml --input input.csv
   ```

   `--normalize` จำเป็น เพราะยอดเงิน (หลักพัน) กับ `month_sin` (−1 ถึง 1) ต่างสเกลมาก

4. **ฝึกใหม่ด้วยทุกแถว** แล้วทายเดือนถัดไปของทุกหมวด ค่าติดลบปัดเป็น 0

โค้ดอยู่ที่ [`finance/ml.py`](../finance/ml.py) และ tests ที่ [`tests/test_ml.py`](../tests/test_ml.py)

## 6. ใช้ผลอย่างไรดี

- ใช้เป็นตัวตั้งงบเดือนหน้าในแท็บ **งบประมาณ** แล้วปรับตามแผนจริง
- ถ้า MAE ของทุกวิธีสูงพอๆ กัน แปลว่ารายจ่ายคุณผันผวน ตัวเลขคาดการณ์จึงเป็นแค่ค่ากลาง ควรเผื่อเงินไว้
- รายจ่ายก้อนใหญ่ครั้งเดียว (ซื้อของชิ้นใหญ่ ค่ารักษา) ทำให้โมเดลเพี้ยนได้ ถ้าอยากได้ตัวเลขนิ่งขึ้น ให้แยกหมวดสำหรับรายจ่ายพิเศษ
