# ใช้ไฟล์ CSV ของคุณกับ C Machine Learning Lab

คู่มือนี้ใช้ Windows PowerShell และ Linear Regression เป็นตัวอย่าง ไม่ต้องย้ายหรืออัปโหลดข้อมูลเข้าโปรแกรมด้วยหน้าต่าง: CML Lab เป็นโปรแกรม command line ที่รับ path ของไฟล์

## 1. วางไฟล์ข้อมูล

แนะนำให้เก็บไฟล์ไว้นอก repository เพื่อไม่ให้ข้อมูลส่วนตัวปะปนกับ Git:

1. เปิด File Explorer แล้วเข้า `Documents`
2. สร้างโฟลเดอร์ `cml-data`
3. วางไฟล์ฝึก เช่น `train.csv` ไว้ที่ `C:\Users\<ชื่อผู้ใช้>\Documents\cml-data\train.csv`

ถ้าต้องการให้ Codex ช่วยดูรูปแบบไฟล์ ให้แนบ CSV ในแชตได้ แต่การรันบนเครื่องของคุณยังต้องมีไฟล์อยู่ในโฟลเดอร์ local ตาม path ที่ส่งให้คำสั่ง

## 2. จัด CSV ให้โปรแกรมอ่านได้

ข้อมูลฝึกต้องเป็นตารางตัวเลข คั่นคอลัมน์ด้วย comma (` , `) และมีหนึ่งตัวอย่างต่อแถว ตัวอย่างพยากรณ์ราคา:

```csv
size,rooms,price
40,1,8000
50,2,10000
60,2,12000
70,3,14000
80,3,16000
```

คอลัมน์ `size` และ `rooms` เป็น features ส่วน `price` เป็น target ที่ต้องการทำนาย หัวคอลัมน์ควรใช้ตัวอักษรอังกฤษ ตัวเลข และ `_` และต้องไม่ซ้ำกัน

ถ้าไฟล์เริ่มจาก Excel ให้ใช้ **Save As → CSV UTF-8 (Comma delimited)** แล้วตรวจว่า:

- ไม่มีช่องว่างหรือค่าที่หายไป
- ทุกคอลัมน์ที่ใช้เป็นตัวเลข ไม่มีชื่อหมวดหมู่หรือวันที่
- คั่นหลักทศนิยมด้วยจุด เช่น `12.5` และคั่นคอลัมน์ด้วย comma
- ไม่มีข้อความในเครื่องหมาย quote หรือบรรทัดว่าง
- ไฟล์ไม่เกิน 16 MiB, 100,000 แถว และ 2,000,000 ช่องตัวเลข

ถ้ามีคอลัมน์ประเภทหมวดหมู่ ต้องแปลงเป็นตัวเลขก่อน และจด mapping ไว้ เช่น `อาหาร=0`, `เดินทาง=1` การแทนรหัสนี้ไม่ได้ทำให้หมวดหมู่มีลำดับหรือความหมายเชิงปริมาณโดยอัตโนมัติ

รายละเอียด CSV ที่ parser รองรับอยู่ใน [ADR-001](adr-001-dataset-csv.md)

## 3. Build โปรแกรม

เปิด PowerShell แล้วเข้าโฟลเดอร์โปรเจกต์ จากนั้น build CLI:

```powershell
cd <โฟลเดอร์ที่ clone ไว้>\c-machine-learning-lab
.\build.bat
```

## 4. ฝึกโมเดล ประเมินผล และสร้างกราฟ

จากโฟลเดอร์หลักของโปรเจกต์ รันคำสั่งนี้ โดย `--target 2` หมายถึงคอลัมน์ที่ 3 (`price`) เพราะ index เริ่มนับจากศูนย์:

```powershell
python scripts/run_linear_csv.py --data "$env:USERPROFILE\Documents\cml-data\train.csv" --target 2 --header
```

สคริปต์จะแบ่งข้อมูลแบบสุ่มเป็น train/test 80/20, ปรับสเกล features โดยคำนวณจาก train เท่านั้น แล้วเรียก CML Linear Regression เพื่อฝึกและทำนาย test set

ผลลัพธ์จะอยู่ใน `build\user-regression\`:

- `prediction.svg` — กราฟคะแนนจริงเทียบกับคะแนนที่โมเดลทำนาย เปิดด้วยการดับเบิลคลิกใน File Explorer
- `metrics.txt` — MAE, RMSE และ R²
- `predictions.csv` กับ `test-actual.csv` — ค่าทำนายและค่าจริงของ test set ตามลำดับ
- `model.cml` — โมเดลที่ฝึกจากส่วน train

ถ้า CSV **ไม่มีแถวหัวตาราง** ให้เอา `--header` ออก ส่วน `--target` ยังคงอ้างถึงตำแหน่งคอลัมน์เดิม

### อ่านกราฟอย่างไร

- แกนนอนคือค่าจริงของ target; แกนตั้งคือค่าที่โมเดลทำนาย
- เส้นประสีแดงคือแนวทำนายได้ตรงพอดี จุดยิ่งใกล้เส้นยิ่งทำนายใกล้ค่าจริง
- จุดเหนือเส้นหมายถึงโมเดลทำนายสูงกว่าค่าจริง; จุดใต้เส้นหมายถึงทำนายต่ำกว่า
- MAE คือขนาดความคลาดเคลื่อนสัมบูรณ์เฉลี่ย หน่วยเดียวกับ target
- RMSE ใช้หน่วยเดียวกัน แต่ลงโทษความผิดพลาดก้อนใหญ่หนักกว่า MAE
- R² ใกล้ 1 มักหมายถึงอธิบายความแปรปรวนใน test set ได้ดี; ใกล้ 0 หมายถึงไม่ดีกว่าการทายค่าเฉลี่ยมากนัก และอาจติดลบได้

ตัวอย่าง: ถ้า target เป็นราคาเงินบาท MAE `500` แปลว่าค่าทำนายคลาดเคลื่อนเฉลี่ยประมาณ 500 บาทบน test set นี้ ไม่ได้แปลว่าความผิดพลาดทุกแถวเท่ากับ 500 บาท

## 5. ทำนายข้อมูลใหม่

สร้าง `predict.csv` โดยใส่เฉพาะ feature columns เรียงลำดับเหมือนในไฟล์ฝึก แต่ **ไม่มี header และไม่มี target**:

```csv
55,2
75,3
```

ส่ง `--predict` ให้สคริปต์ เพื่อฝึก/ประเมินและทำนายข้อมูลใหม่ในรอบเดียว:

```powershell
python scripts/run_linear_csv.py --data "$env:USERPROFILE\Documents\cml-data\train.csv" --target 2 --header --predict "$env:USERPROFILE\Documents\cml-data\predict.csv"
```

ค่าทำนายข้อมูลใหม่อยู่ที่ `build\user-regression\new-predictions.csv` ตามลำดับแถวใน `predict.csv` สคริปต์จะใช้การแบ่งข้อมูลและสเกลแบบเดิมทุกครั้งเมื่อ seed และไฟล์ฝึกไม่เปลี่ยน

## หมายเหตุ

- กราฟเป็นผลจาก test set ที่สุ่มแยกจากข้อมูลเดียวกัน ไม่ใช่กราฟฝึก และไม่ได้ยืนยันว่าโมเดลจะทำนายข้อมูลอนาคตได้ดี
- สคริปต์นี้ใช้ random split หากข้อมูลเป็นอนุกรมเวลา เช่น ค่าใช้จ่ายรายเดือน การสุ่มอาจทำให้ประเมินสูงเกินจริง ควรแยกช่วงเวลาท้ายสุดเป็น test แทน
- `model.cml` จากสคริปต์นี้ฝึกด้วยข้อมูลประมาณ 80% เพราะกันอีก 20% ไว้ทดสอบ
- ดูตัวเลือก CLI เพิ่มเติมด้วย ` .\build\cml-lab.exe --help ` และดูตัวอย่าง O-NET ไทยที่ [examples/thai-onet](../examples/thai-onet/README.md)
